## 2025-05-14 - Application Hardening and Input Validation
**Vulnerability:** Information disclosure via X-Powered-By header, potential DoS via large JSON payloads, and lack of input validation on email fields.
**Learning:** Even small applications benefit from baseline security hardening like disabling technology fingerprinting and enforcing payload limits.
**Prevention:** Always include security headers and basic input validation (length and format) in the initial scaffolding of an application.
